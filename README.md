# Projeto de Hospedagem Web — Windows Server 2022 e IIS

## Sobre o projeto
Projeto acadêmico de infraestrutura de TI com configuração de servidor web e hospedagem de site utilizando o IIS.

## Tecnologias utilizadas
- Windows Server 2022
- Internet Information Services (IIS)
- Hyper-V
- HTML e CSS (quando aplicáveis)

## Objetivos
- Configurar um servidor web.
- Hospedar e testar o acesso a um site.
- Aplicar conhecimentos de infraestrutura e redes.

## Aprendizados
Prática de configuração de servidores, hospedagem web e diagnóstico de conectividade.

Projeto desenvolvido para fins acadêmicos.
